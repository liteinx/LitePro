# Watch Together (w2g) - APK Distribution Site

A modern APK distribution platform for the Watch Together app, allowing users to download custom builds and variants through unique shareable codes.

## Features

- **APK Distribution System**: Distributes multiple APK files through unique 5-character shareable codes
- **URL-Based APK Selection**: Uses `?r=CODE` parameters to serve specific APK versions
- **Multi-Language Support**: 8 languages (EN, AR, ES, FR, DE, ZH, HI, PT) with RTL support for Arabic
- **Responsive Design**: Mobile-friendly with modern CSS animations and effects
- **Dynamic Content**: Page title, tagline, and download behavior change based on URL parameters
- **Code Generation**: Generates unique 5-character codes (A-Z, 2-9, excluding I/O/0/1)
- **Collision Detection**: Automatically generates new codes if existing ones are detected
- **Download Tracking**: Console logging of download events and timestamps
- **Error Handling**: Graceful fallback to default APK for invalid codes
- **JSON Configuration**: Centralized configuration file managing APK mappings

## Usage

### Adding a New APK

Use the provided script to add new APK files:

```bash
./add-apk.sh <path-to-apk> [app-name]
```

Example:
```bash
./add-apk.sh ~/Downloads/w2g-mod.apk "Custom Build"
```

The script will:
1. Validate the APK file
2. Generate a unique 5-character code
3. Copy the APK to the w2g directory
4. Update `apks.json` configuration
5. Provide a shareable URL

### Share Links

Once an APK is added, you can share it using the generated code:

```
https://liteinx.github.io/LitePro/w2g/?r=ABCDE
```

Replace `ABCDE` with the actual code generated by the script.

## Features in Detail

### APK Management

- **Add APK**: Use `add-apk.sh` script to add new builds
- **Unique Codes**: Each APK gets a unique 5-character code
- **Version Tracking**: Track when each APK was added and download counts
- **Safe Overwrites**: Script prompts before overwriting existing files

### Multi-Language Support

The site supports 8 languages:
- English (EN)
- Arabic (AR) - with RTL support
- Spanish (ES)
- French (FR)
- German (DE)
- Chinese (ZH)
- Hindi (HI)
- Portuguese (PT)

Language is automatically detected from the browser, or manually selected using the language switcher.

### URL Parameters

- `?r=CODE` - Load specific APK by code
- No parameter - Shows default APK

## Configuration

### apks.json

The `apks.json` file manages all APK mappings:

```json
{
  "default": "w2g_default.apk",
  "apps": {
    "CODE1": {
      "filename": "app_name.apk",
      "name": "Display Name",
      "added": "2026-03-23T00:00:00Z",
      "downloads": 0
    }
  }
}
```
